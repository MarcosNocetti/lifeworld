# LifeWorld — 50 decisões

Jogo-instrumento de coleta do Trabalho de Graduação de Marcos Gabriel Nocetti Santos
(Fatec Sorocaba): como pessoas interpretam objetivos escritos em linguagem natural,
comparadas a modelos de linguagem no mesmo mundo simulado.

**Jogar:** https://marcosnocetti.github.io/lifeworld/

Este repositório é um alvo de deploy — o código-fonte, os testes de fidelidade do
simulador e o histórico vivem no repositório do TCC (privado). Participação anônima;
detalhes no termo de consentimento dentro do próprio jogo.
